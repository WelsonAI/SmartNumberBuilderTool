# Smart Number Builder Tool

An interactive number-sense and place-value tool for Malaysian primary pupils from Year 1 to Year 6.

## Learning modes

- Match numbers with number words in both directions
- Build a number from its expanded value
- Decompose a number by place value
- Form the largest or smallest number from given digit cards
- Arrange numbers in ascending or descending order

The number ranges follow the progression from 0–100 in Year 1 to 0–10,000,000 in Year 6. The tool supports Bahasa Melayu, Chinese, and English, with language-specific number-word rules. It is designed for desktop, tablet, and mobile use with both drag-and-drop and tap-to-place controls.

## Run locally

Open `index.html` in a modern browser. No installation or build step is required.
