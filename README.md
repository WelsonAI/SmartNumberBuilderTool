# Smart Number Builder Tool

An interactive number-sense and place-value tool based on SJKC Year 2 and Year 3 Mathematics Jilid 1.

## Learning modes

- Build a number from its expanded value
- Decompose a number by place value
- Form the largest or smallest number from given digit cards
- Arrange numbers in ascending or descending order

The tool supports Bahasa Melayu, Chinese, and English. It is designed for desktop, tablet, and mobile use with both drag-and-drop and tap-to-place controls.

## Run locally

Open `index.html` in a modern browser. No installation or build step is required.
